# Мои покупки, неделя 4

Интерактивный дашборд на Vue 3.5.13 и D3 7.9.0.

Публичный сайт: https://chibrus.github.io/purchases-week4/

index.html содержит все стили, код, данные и 338 изображений. Внешних CDN и серверного API нет. Исходный проект с отдельными файлами, подготовкой данных, лицензиями и тестами находится в source.zip.

Показаны заказы, траты и средняя скидка за последний месяц, динамика за 24 месяца, рейтинг товаров в штуках и рублях, категории и история цены покупки. Есть фильтры, сортировка, поиск и подсказки.

Методика: COUNTD(order_id), SUM(amount), SUM(quantity), AVG(discount) в рублях на товарную строку. Цена покупки по месяцу = SUM(amount) / SUM(quantity). Последний месяц данных может быть неполным. Заказы по категориям не складываются.

Учебный датасет первой недели, вариант C. Адреса и время доставки исключены, исходные ID заказов заменены техническими номерами. Для 72 изображений принято предположение о соответствии учебного бренда Груша бренду Лавка в positions.csv; остальное название и категория совпадают. Полная история сопоставлений сохранена в исходном проекте.
